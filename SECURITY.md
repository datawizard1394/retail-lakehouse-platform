# Security

This repository processes synthetic demonstration data only. Do not use it to
store personal, customer, employer, or regulated information.

For a privately reported vulnerability, contact the repository owner through
their GitHub profile rather than opening an issue with exploit details.

The Terraform example is not deployment-ready. A real implementation requires
organization-specific threat modeling, private connectivity, managed identity,
least-privilege access, secret management, audit logging, key management,
policy-as-code, budget controls, and reviewed state storage.
