# Contributing

This is a portfolio demonstration, but review-quality contributions are welcome.

1. Keep every fixture fictional and use reserved domains such as `example.test`.
2. Add a regression test for behavioral changes.
3. Preserve deterministic output for a fixed seed and configuration.
4. Run `make test` and `make lint`.
5. Update contracts and the ADR log when changing public semantics.
6. Never commit credentials, customer data, employer data, Terraform state, or
   claims that the illustrative infrastructure has been deployed.

Pull requests should explain the data contract impact, migration behavior,
failure semantics, and evidence used to validate the change.
